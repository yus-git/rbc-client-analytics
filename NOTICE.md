# Scope and attribution

This is a synthetic Client Analytics reference demonstration prepared for an RBC
customer discussion. It contains no actual customer records, account balances,
credentials, or tenant configuration. The name is contextual: no endorsement,
certification, or production approval by RBC, Microsoft, Databricks or other
vendors is implied. Product names remain the property of their respective owners.

The seed data and application code were created for this demonstration. External
documentation is linked, not redistributed. No open-source license has been
assigned here: the repository owner must approve licensing and external
distribution before making the repository public. Private repository access
should be granted only to approved reviewers.

Use an isolated non-production environment. Service subscriptions, regional
availability, tenant policies and cloud costs are the deployer's responsibility.
