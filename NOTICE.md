# Scope and attribution

This Client Analytics reference implementation uses exclusively synthetic data.
It contains no actual customer records, account balances, credentials or
deployment-specific tenant configuration. The repository name does not imply
endorsement, certification or production approval by RBC, Microsoft, Databricks
or other vendors. Product names remain the property of their respective owners.

The seed data and application code were created for this reference implementation.
External documentation is linked, not redistributed. This repository does not
currently include an open-source license. Public availability does not grant
additional reuse or redistribution rights; contact the repository owner for
licensing information.

Perform initial deployment and acceptance testing in an isolated non-production
environment. Service subscriptions, regional availability, tenant policies,
production-readiness assessment and cloud costs remain deployment responsibilities.
